VERCEL FIXED VERSION

1. Upload the CONTENTS of this folder to Vercel (not the ZIP file itself).
2. Vercel must serve index.html at the root.
3. In Firebase Authentication, enable Email/Password.
4. Create these two users:
   her@ourlittlespace.app
   him@ourlittlespace.app
5. Their Firebase passwords are the answers entered on the question screens.
6. In Firebase Firestore, create the database.
7. Publish firestore.rules.
8. Firebase Authentication -> Settings -> Authorized domains:
   add your Vercel domain, e.g. your-project.vercel.app
9. Open your Vercel URL, not chat.html directly.

IMPORTANT FIX:
The login page signs out only when it opens. It no longer signs the user out immediately after a successful login.
The Firebase browser-session login is then available to chat.html.

If Vercel still shows a blank page:
- Open the Vercel site.
- Press F12 -> Console.
- Send the red error shown there.
